## Featured Projects

### 01. Metal Surface Defect Inspection

An AI/ML-based project focused on identifying and inspecting defects in industrial metal surfaces using image processing and machine learning approaches.

**Key Objectives:**
- Explore automated industrial quality inspection.
- Work with metal surface image datasets and XML annotations.
- Convert XML annotations into structured CSV files.
- Process and prepare image datasets for machine learning.
- Explore computer vision and deep learning techniques for defect detection.

**Technologies:** Python, Pandas, NumPy, XML, Computer Vision, Machine Learning.

### 02. Women Safety Route Finder

A safety-focused route-finding application developed as a GDG hackathon project, designed to help users identify potentially safer routes based on environmental factors.

**Key Features:**
- Safer route suggestions considering environmental information.
- Streetlight and crowd-density considerations.
- SOS emergency assistance.
- Emergency contact management.
- Map integration.

**Technologies:** HTML, CSS, JavaScript, Firebase, Google Maps API.
